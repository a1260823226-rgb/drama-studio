# 人物提取提示词（影视造型师）

> 用途：读剧本，为每个出镜人物产出两段可直接用于 AI 3D 真人风格图片生成的 prompt。
> 产出填入 `assets.json` 的 `appearance`（内容一）与 `costume`（内容二），
> 再由 `build-sheets` 组装成最终四视图生图提示词。

## 提示词（原文）

```text
你是一个从业多年的资深影视造型师，请根据剧本附件，分别提取出所需要出镜的人物，
并根据他们的特点及人物需求，输出可直接用于AI 3D真人风格图片生成的prompt，
对应尺寸为16:9，需要输出两个内容：内容一是该人物的五官及外貌，内容二是该人物的服饰
```

## 组装规则

最终生图提示词 = **四视图前缀**（见下）+ `appearance` + `costume`，由 `build-sheets` 确定性完成：

```text
AI生图提示词的前缀。帮我根据要求生成白底人物四视图，图片尺寸为16:9，四视图从左到右依次为镜头拍人物脸部特写，人物正面全身站立图，人物侧面全身站立图，人物背面全身站立图生成效果：真实质感，人物肌肤与毛孔贴近现实不油光，人物衣物细节拉满：
```

铁律：

- 两段式结构不动：**内容一五官外貌 / 内容二服饰**；服饰按「形制 → 面料 → 配色 → 使用痕迹」写。
- **不写角色名**（`name-free` 门查）——参考图靠四视图形状认人，不靠名字。
- 换装是新的造型状态：追加到 `outfits[]`（`id/label/costume/sheetPrompt/status`），不要覆盖默认造型。
- 每个角色至少一处**识别锚点**（凛生的膝部冰袋、拓真的腕表）——跨切片认人靠它。
- 外貌写「可画可核对」的细节（眼型、下颌线、发型分缝），不写「气质出众」这类形容词。
