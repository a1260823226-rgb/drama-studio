# 场景提取提示词（影视场景美术指导）

> 用途：读剧本，提取构建画面所必需的物件清单（分层），并产出场景空镜生图提示词。
> 剧情之间要衔接，场景里的物件就必须按**必要性与优先级**说清楚——这是跨切片不漂移的根。

## 提示词（原文）

```text
# 角色
你是一位资深的影视场景美术指导与AI生图提示词工程师，擅长从文本中拆解出构建画面所必需的具体物件。

# 任务
阅读用户提供的文本，提取其中描述的、或根据场景逻辑必然存在的"生图必要物件"，输出一份结构化清单。

# 提取原则
1. 只提取"可视物件"：能被画出来的实体物品、人物、建筑、自然元素、光影装置等。
2. 区分层级：
   - 核心物件：文本明确提到、且构成场景主体的物件
   - 环境物件：构成背景与氛围的物件（如地面、墙面、天空、远景）
   - 隐含物件：文本未明说，但该场景逻辑上必然出现的物件（如"咖啡馆"必然有桌椅、杯子、吧台）
3. 忽略：抽象情绪、心理活动、无法可视化的比喻。
4. 每个物件给出：名称、类别、在画面中的作用、建议的视觉特征（材质/颜色/形态）。

# 输出格式
以 Markdown 表格输出，字段如下：
| 序号 | 物件名称 | 层级 | 类别 | 画面作用 | 建议视觉特征 |

最后附一段"场景整体氛围总结，且对应的生图尺寸为16:9"，用于指导生图风格。

# 输入文本
```

## 落地规则

- 表格的每一行 → `assets.json` 的 `scenes[].objects[]`（`name/level/category/role/visual`）。
- 氛围总结 → `scenes[].atmosphere`；最终 `sheetPrompt` 由 Agent 把物件清单+氛围写成一段**空镜描述**。
- `scene-objects` 门：核心+环境必须有，层级只能取 核心/环境/隐含，每件必须有画面作用与视觉特征。
- **隐含物件是连续性关键**：剧本没写但逻辑必然存在的（提罐女子的封口麻布、罐里的斋饭），写进去——不写，模型每次生成都会即兴发明。

## 空镜提示词样例（乱石坡）

```text
东方神话写实电影风格，荒山乱石坡空镜，无人场景。画面中景是一组灰白巨石，表面被雨水冲出浅沟，背阴面生着青苔；巨石前一块半人高的平顶石，石面被坐得发亮，边缘有裂纹，石上放着一只粗陶青砂罐与一只釉色发暗的绿磁瓶，罐口蒙着麻布。

石群之间是一道半人深的浅沟，沟底潮湿，堆着落叶。坡面枯草成簇，碎石遍布，踩上去会滑。远处浓雾被日光顶开一半，低处仍糊着白气。偏冷的中性日光从右上方斜下，白石反光晃眼，泥地显脏。镜头中景广角，平视略低，巨石压住画面右侧三分之一。写实影视剧照质感，电影级画质。画面中不出现任何可读文字、数字、标语、品牌名、标签或说明字样。
```

写法要点：

1. **空镜**：无人、无手（`no people` 语义写进描述）。
2. **按空间顺序铺陈**：中景巨石 → 平石 → 浅沟 → 坡面 → 远处，让模型有布局可依。
3. **材质/颜色/形态具体**：粗陶、釉色发暗、麻布封口——不写"干净的"这种废话。
4. **光线与机位**：中性斜光、中景广角略低视角。
5. **结尾必须声明无可读文字**（`scene-no-text` 门查）：文字后期叠加，不让模型生成乱码标语。
6. 同一场景的不同时段/光线 → 换 `atmosphere` 与 `sheetPrompt` 重出一张，UUID 不变。
