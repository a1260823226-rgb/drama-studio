# Stage 1 · 依据剧本制作资产

目标：剧本里出现的每个**角色**、**场景**、**叙事道具**，都有一份设计字段、一张（组）参考图、一个平台 UUID。
下游所有切片 Prompt 用 `@UUID` 绑定它们——**身份保真度卸载给参考图，文本只写增量**。

产出范式（经过实战验证的两条流水线）：

- **人物**：造型师提示词产出「外貌 + 服饰」两段 → 组装成**白底四视图**生图提示词（16:9）→ 出图上传 → 登记 UUID。
- **场景**：美术指导提示词产出**分层物件清单**（核心/环境/隐含）→ 写成**空镜**生图提示词 → 出图上传 → 登记 UUID。

## 1. 人物：从剧本到四视图

### 提取（character-extract.md）

把剧本喂给「资深影视造型师」提示词，每个出镜人物产出两段：

1. **五官及外貌**：年龄性别身份 → 身高体型 → 脸型五官 → 皮肤 → 发型，落到可画可核对的细节。
2. **服饰**：形制 → 面料 → 配色 → 收边配饰 → 使用痕迹；形制排第一（转英文后中段细节会丢）。

铁律：**不写角色名**（四视图形状认人，不靠名字）；每人至少一处**识别锚点**（孙悟空的金箍、唐僧的九环锡杖）。

### 组装（build-sheets）

```bash
python {baseDir}/scripts/drama_studio.py build-sheets <项目>-assets.json            # 预览
python {baseDir}/scripts/drama_studio.py build-sheets <项目>-assets.json --apply    # 写回并盖指纹
```

`sheetPrompt = 四视图前缀 + appearance + costume`，确定性组装，模型不参与：

```text
AI生图提示词的前缀。帮我根据要求生成白底人物四视图，图片尺寸为16:9，四视图从左到右依次为镜头拍人物脸部特写，人物正面全身站立图，人物侧面全身站立图，人物背面全身站立图生成效果：真实质感，人物肌肤与毛孔贴近现实不油光，人物衣物细节拉满：
```

四视图 = 一张图里四个视角（脸部特写 + 正/侧/背面全身），白底 16:9。它同时是**身份锚点、服装拓扑母版、比例参照**——一张图解决三件事，比多张链式图更稳（链式累积漂移，单张重出牵连一串）。

### 换装

换装是新的造型状态，不是覆盖：追加到 `outfits[]`（`id/label/costume/sheetPrompt/status/generatedFrom`）。默认造型与比赛造型各一张四视图，UUID 不变（同一角色），切片里按需引用。

### 出图与登记

出图后把 `images[].status` 改为 `linked`；抽帧验收后改 `accepted`。参考图硬门槛：单边 300-5760 px、宽高比 0.4-2.5、≤20MB、四视图比例 16:9。门查不了的（长相、角度、比例）**靠眼睛看图**。

## 2. 场景：从剧本到空镜

### 提取（scene-extract.md）

把剧本喂给「影视场景美术指导」提示词，产出**分层物件清单**：

| 层级 | 定义 | 例（乱石坡） |
|---|---|---|
| 核心 | 文本明确提到、构成场景主体 | 灰白巨石、坡口平石、青砂罐与绿磁瓶 |
| 环境 | 构成背景与氛围 | 半散的雾、枯草碎石、乱石间的浅沟 |
| 隐含 | 未明说但逻辑必然存在 | 斋饭残渣、罐口的麻布封口 |

**隐含物件是连续性的根**：剧本只写了「提罐送饭」，但罐子、封口、残渣逻辑上必然存在——不登记，模型每次生成都会即兴发明一个，跨切片必漂。剧情之间要衔接，物件就必须按必要性与优先级说清楚。

### 组装空镜提示词

`sheetPrompt` 由 Agent 把物件清单 + 氛围总结写成一段**空镜描述**，按空间顺序铺陈：

```text
东方神话写实电影风格，荒山乱石坡空镜，无人场景。画面中景是一组灰白巨石，表面被雨水冲出浅沟……
巨石前一块半人高的平顶石，石上放着一只粗陶青砂罐与一只釉色发暗的绿磁瓶，罐口蒙着麻布……
石群之间是一道半人深的浅沟……坡面枯草成簇，碎石遍布……远处浓雾被日光顶开一半……
偏冷的中性日光从右上方斜下，白石反光晃眼，泥地显脏……镜头中景广角，平视略低，巨石压住画面右侧三分之一……
写实影视剧照质感，电影级画质。画面中不出现任何可读文字、数字、标语、品牌名、标签或说明字样。
```

六条写法：① 空镜无人无手；② 中景巨石→平石→浅沟→坡面→远处的空间顺序；③ 材质颜色形态具体（粗陶、釉色发暗、麻布封口）；④ 光线与机位写明；⑤ **结尾声明无可读文字**（`scene-no-text` 门查，文字后期叠加）；⑥ 同时段/光线变体换 `atmosphere` 重出，UUID 不变。

### 叙事道具

场景内静态物件进 `scenes[].objects`；**跨场景流转、有状态变化**的才建道具卡（`states[]` 状态机：数量/位置/朝向/开合/完好/干湿/文字图层）。

## 3. UUID 登记与状态机

- UUID 由**用户的生成平台**给出（上传参考图后平台分配），或本地 `uuid-new` 预生成。
- `assets.json` 是 UUID 的唯一事实源；切片里只写名字，编译时由 `compile-slices` 解析成 `@UUID`。
- 图的状态：`pending → linked → accepted`。**没有 `linked/accepted` 的参考图，`reference-image` 门不过，Stage 3 拒绝编译**——模型会当场发明一张脸。
- **改了描述必须重出图**：`generatedFrom` 是出图时提示词的指纹，对不上即过期（`sheet-fresh` 门拦）。改 appearance/costume → 重跑 `build-sheets --apply` → 重出图 → 重新验收。

## 4. 声音

每个有台词的角色锁 `voice.timbre / pitch / pace / accent`（`voice-lock` 门查）。声线圣经服务于配音与口型验收：同一角色跨切片声线必须一致，ASR 转写 + 人工 A/B 盲听抽查。

## 命令

```bash
python {baseDir}/scripts/drama_studio.py seed-assets <项目>-scenes.json --out <项目>-assets.json
python {baseDir}/scripts/drama_studio.py build-sheets <项目>-assets.json --apply
python {baseDir}/scripts/drama_studio.py uuid-new 孙悟空 唐僧 猪八戒 沙僧 白骨精
python {baseDir}/scripts/drama_studio.py validate-assets <项目>-assets.json --scenes <项目>-scenes.json
```
