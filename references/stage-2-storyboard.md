# Stage 2 · 分镜（15 秒切片）

目标：把剧本切成一组**独立可用、拼接完整还原剧情**的 15 秒切片，每个切片是一份可验收的生成合同。
切分是创意工作，但六条硬律全部由 `validate-storyboard` 的 18 道门强制执行——**门不过，不编译**。

## 切片数据结构

```jsonc
{
  "id": "S02-02",                 // 场次序号-切片序号，唯一
  "sceneId": "1-2",               // 归属场次（段内同场，换景必开新场）
  "title": "编出来的家世",         // 片段小标题
  "seconds": 15,
  "cutPoint": "line-end",         // 本切片开场所对应的断点类型
  "size": "中近景",               // 景别：按剧情匹配（模板四选一：中景/中近景/特写/全景）
  "camera": "推镜",               // 运镜：一个主要动作
  "shotLanguage": "中近景侧机位缓推，唐僧与女子隔平石对置，浅景深虚掉八戒的脸，推至罐口特写时切走。",
                                // 镜头语言：景别层次/机位角度/运镜方式/构图/与前后镜头的组接，一句话（≤80字）
  "setting": "平石两侧，日光落在石面上，罐子搁在八戒脚边",   // 环境铺垫（可选）
  "actionUnits": [                // 3-5 个有效动作单元，剔除眨眼级细碎动作
    "唐僧眉心锁起，往前半步，把马缰绕在手上",
    "女子垂眼答话，指尖绞住衣角，绞得指节发白",
    "猪八戒抢过话头，一手掀开罐盖，热气腾起"
  ],
  "dialogue": [                   // 台词逐字来自剧本，不改一个字节
    { "speaker": "唐僧", "emotion": "压低声", "line": "山深路险，怎好独自送饭？" }
  ],
  "characters": ["唐僧", "猪八戒", "沙僧", "村姑"], // 画内人物（写名字，编译时解析 UUID）
  "props": ["青砂罐与绿磁瓶"],
  "entryState": "女子站在平石前，青砂罐已到猪八戒手里，唐僧目光落在她的绣鞋上",
  "exitState": "猪八戒揭开罐盖，热气腾起，唐僧合掌欲谢",
  "continuity": "chain",          // scene-start / chain / cut / reanchor
  "reanchorFrom": [],             // reanchor 时必填：["C01","C02","S01"]
  "intense": false,               // 激烈对峙：台词上限放到 40
  "status": "planned"             // planned → generated → reviewed → accepted | repair | rejected
}
```

## 六条切分律

### 1. 时长：每切片恰好 15 秒

`seconds` 必须等于 `params.sliceSeconds`。15 秒是单次生成的容器，不是内容上限。

### 2. 台词：25-35 汉字，激烈 ≤40

- 按**汉字**计（标点不计）：听说裁判长为难你了 = 9 字。
- 单切片全部台词合计落在 25-35；激烈对峙标 `intense: true` 可到 40。
- 超长台词必须拆到下一片；**拆分后拼接必须逐字还原**（`dialogue-coverage` 门按场次拼接比对，不增不减不改）。
- 无台词切片（纯动作/空镜）不设下限，也不写 `{}` 台词块。
- 每句台词写明唯一说话者、可见嘴型；非说话者闭嘴状态在验收时查。

### 3. 动作单元：3-5 个

- 每个切片 3-5 个**有效动作单元**（姿态、走位、表情、道具交互、冲突细节）。
- 剔除眨眼、呼吸起伏这类无意义细碎动作；复杂冲突、连续打斗必须切分。
- 事件负载纪律：一个 15 秒切片同时只承担**一个主要道具系统 + 一条高风险物理链 + 一个主要情绪回报**。
- 说完一句话后不许静止：台词前后安排反应、退出动作（呼吸、视线转移、重心变化）。

### 4. 断点：只切在这五种节点

| cutPoint | 含义 |
|---|---|
| `line-end` | 单句台词结束 |
| `entrance` | 人物入场 |
| `exit` | 人物离场 |
| `action-turn` | 重大动作转折 |
| `emotional-pause` | 情绪停顿 |

第一个切片标 `scene-start`。**上一片的结尾动作，必须作为下一片的起始画面**——这不是文风要求，是 `continuity` 门的硬检查。

### 5. 连续性：chain / cut / reanchor

```
scene-start ─chain─▶ chain ─chain─▶ [链深度到 3] ─reanchor─▶ chain ─cut─▶ 下一场
```

- `chain`：本片首帧 = 上一片验收尾帧；`entryState` 必须逐字接住上一片 `exitState`。
- `reanchor`：链深度到限、换装、或发现漂移时，从角色/场景母版重新开镜；入场状态显式声明，并列出 `reanchorFrom`。重置链深度。
- `cut`：刻意剪辑（不承诺帧连续），用于场景边界或节奏切换。
- 跨场（`sceneId` 变化）**禁止 chain**——场景边界从母版开镜。
- 链深度 ≤ `params.maxChainDepth`（默认 3）。
- 好的接缝至少保住两项：动作 / 方向 / 形状 / 视线 / 声音 / 光线。

### 6. 景别与运镜：逐镜匹配

- 每个切片一个主要运镜，有起点有终点；运镜不能只为"动起来"，静止更能表达意图时就静止。
- 景别承载关系：全景=处境与尺度，中景=对峙，中近景=情绪，特写=关键道具/微表情。
- 每个切片回答"为什么这样拍"；`shot-variety` 门拦"全部复用一套"。

## 镜头语言：一句话说清视觉意图

镜头语言是**通过摄影机拍摄的画面传递拍摄者意图的视觉表达体系**——利用景别变化、拍摄手法和画面组合实现叙事功能。它本质上没有固定规律，任何通过镜头传递创作者意图的表达都算数；但工具箱是稳定的，就四层：

### ① 景别（景距与视角）

| 景别 | 画面规格 | 叙事功能 |
|---|---|---|
| 极远景 / 大远景 / 远景 | 人物小如蚂蚁，环境吞没人 | 处境、孤独、人与世界的融合 |
| 大全景 | 主体+周围大环境 | 环境介绍，最广的镜头 |
| 全景 | 人物全身/场景全貌 | 动作与所处环境的关系 |
| 小全景 | 顶天立地又相对完整 | 压迫或渺小 |
| 中景 | 小腿以上（七分像） | 表演性场面常用，均衡平稳 |
| 中近景 / 半身景 | 腰到头 | 关系与情绪 |
| 近景 | 胸部以上 | 逼近观察，情绪冲击 |
| 特写 / 大特写 | 肩部以上 / 局部细部 | 强调瞬间反应、关键道具（眉、眼、扳机） |

用法：`景别` 字段按模板四选一（中景/中近景/特写/全景）；更细的层次（大远景、小全景、大特写、极远景）写进 `shotLanguage`。

### ② 拍摄方式（动态呈现空间关系）

推 / 拉 / 摇 / 移 / 跟 / 升 / 降 / 俯 / 仰 / 甩 / 悬 / 空 / 综；反打、变焦、主观拍摄。
原则：**一个镜头一个主要运动**，有起点有终点，运动必须有动机（揭示、追随、改变什么）。

### ③ 构图与角度（画面内部的权力关系）

- 角度：正 / 侧 / 背 / 平 / 仰 / 俯——高度承载权力与同情，仰拍高大庄严，俯拍宏观展现。
- 层次：前景 / 中景 / 后景——画面纵深；前景压画幅、后景交代环境。
- 三分线、画中画、留白、顶格、景深（浅景深=锁定主体，让环境退后）。
- 构图即关系：两人分置左右=对峙，一大一小=权力差，主体被门框框住=被困。

### ④ 组接方式（镜头之间的语法）

淡入 / 淡出 / 化 / 叠 / 划 / 入画 / 出画 / 定格 / 闪回；切（连续切换 / 穿插切换）；蒙太奇（叙事蒙太奇 / 表现蒙太奇：平行剪辑、交叉剪辑）。
原则：好的接缝至少保住两项——动作 / 方向 / 形状 / 视线 / 声音 / 光线；跳切是节奏工具，不是遮丑手段。

### 写法

`shotLanguage` 一句话（≤80 字），覆盖能覆盖的层：**景别层次 + 机位角度 + 运镜方式 + 构图 + 与前后镜头的组接关系**。例：

```text
特写仰拍，岩壁横线压在画面上缘，指骨与石缝占满前景，绿瞳特写接整片山雾拉远，切成静默。
大全景定场，平视固定机位，石阶作纵深引导线，人物占画面下三分之一，山雾压住上缘留白，长镜头缓起。
```

- 必须落到可执行术语（`shot-language` 门查长度与有无；写虚了只提示不拦，但提示必须理会）。
- 跨切片的镜头语言要成体系：景别阶梯有进退（全景→中景→特写是逼近，反之是疏离），运镜密度有节奏，接缝方式有意图——**单镜头的形态永远不孤立存在**。

## 工作流

1. `seed-storyboard` 出骨架 + 场次计划（台词句/字、动作节拍、预估秒、建议切片数——建议值只是起点，按断点与台词字数调）。
2. 按六律手写 `slices`：先定断点，再填动作单元与台词（从 scenes.json 逐字复制），最后写 entry/exit 状态。
3. `validate-storyboard` 跑到全过；病灶逐条修，**不要为了让门过而改台词**——台词只能回剧本层改。
4. `render` 出报告自查连续性链。

## 常见病灶

| 病灶 | 修法 |
|---|---|
| 单切片台词 41 字 | 拆到下一片，或确认是真激烈对峙后标 `intense` |
| 动作单元 6 个 | 合并同类项或切给下一片 |
| `continuity` 门报接不上 | 把上一片 `exitState` 原文复制为本片 `entryState` |
| `dialogue-coverage` 报对不上 | 台词被改写/漏抄/串场——回 scenes.json 逐字核对 |
| 链深度超限 | 把下一片改 `reanchor`（列母版）或 `cut` |
| 跨场 chain | 场景边界改 `cut` 或 `reanchor` |
