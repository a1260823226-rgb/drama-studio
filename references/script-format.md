# 输入剧本格式规范（分场剧本）

本 skill 的入口是一种**行式分场剧本**。`parse-script` 是严格的：认不出的行直接报错退出（附行号），不猜、不静默跳过。

## 行类型

| 行 | 语法 | 说明 |
|---|---|---|
| 场头 | `场号 场景地点 时间 内/外` | 时间与内外可省：`3-2 青叶大学冰场理疗室 日 内`；地点可含空格（非贪婪匹配到最后一个时间词） |
| 人物 | `人物：名字、名字、名字` | 顿号/逗号/空格分隔；必须是本场第一个内容行 |
| 动作 | `△动作描写` | 可多行；`※` 同义 |
| 特写 | `特写：特写内容` | 转为带 `closeup: true` 的动作节拍 |
| 台词 | `角色（情绪）：台词` | 情绪可省：`角色：台词`；角色名 ≤12 字且不含冒号括号 |
| 注释 | `# 开头` | 跳过 |

```text
3-2 青叶大学冰场理疗室 日 内
人物：凛生、拓真、开太

△凛生坐在理疗床上，右腿做了专业固定，膝盖上敷着冰袋，无法随意活动。
拓真（眼神充满占有欲）：听说裁判长前几天为难你了？
凛生（冷漠）：不关你的事。
特写：冰袋表面的水珠顺着凛生的指尖滑落。
```

## 解析产物 scenes.json

```jsonc
{
  "title": "青叶大学", "lang": "zh", "source": "青叶大学-script.md",
  "scenes": [{
    "id": "3-2", "location": "青叶大学冰场理疗室", "time": "日", "intExt": "内",
    "characters": ["凛生", "拓真", "开太"],
    "beats": [
      { "no": 1, "type": "action", "text": "凛生坐在理疗床上……", "closeup": false },
      { "no": 3, "type": "dialogue", "speaker": "拓真", "emotion": "眼神充满占有欲", "line": "听说裁判长前几天为难你了？" }
    ]
  }]
}
```

- `beats[].no` 场內连号；动作与台词严格按原文顺序。
- 台词原文**逐字保留**（含标点），后续 `dialogue-coverage` 门靠它比对。
- 解析即消毒：`△` 符号只存在于原文，不进任何下游产物。

## 格式不对怎么办

- 报 `无法识别`：把该行改成上表五种行型之一；动作忘写 `△` 是最常见原因。
- 报 `场号重复` / `场头之前出现内容`：检查场号与 `人物：` 行位置。
- 用户只有小说/梗概没有分场剧本：先按本格式改写成剧本再进入管线——**不要绕过解析器**，下游所有门的可追溯性都建立在 scenes.json 上。
