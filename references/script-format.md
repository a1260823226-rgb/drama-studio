# 输入剧本格式规范（分场剧本）

本 skill 的入口是一种**行式分场剧本**。`parse-script` 是严格的：认不出的行直接报错退出（附行号），不猜、不静默跳过。

## 行类型

| 行 | 语法 | 说明 |
|---|---|---|
| 场头 | `场号 场景地点 时间 内/外` | 时间与内外可省：`1-2 白虎岭乱石坡 日 外`；地点可含空格（非贪婪匹配到最后一个时间词） |
| 人物 | `人物：名字、名字、名字` | 顿号/逗号/空格分隔；必须是本场第一个内容行 |
| 动作 | `△动作描写` | 可多行；`※` 同义 |
| 特写 | `特写：特写内容` | 转为带 `closeup: true` 的动作节拍 |
| 台词 | `角色（情绪）：台词` | 情绪可省：`角色：台词`；角色名 ≤12 字且不含冒号括号 |
| 注释 | `# 开头` | 跳过 |

```text
1-2 白虎岭乱石坡 日 外
人物：唐僧、猪八戒、沙僧、村姑

△雾散了一半，乱石坡下传来环佩声。一个青衣女子提着青砂罐、拎着绿磁瓶，从坡下一步步上来。
猪八戒（眼睛发直）：女菩萨，青罐里提的是什么？
村姑（福身一礼）：长老，这是给田中丈夫送的斋饭。
特写：罐盖翻开，长蛆与蛤蟆从斋饭里涌出来。
```

## 解析产物 scenes.json

```jsonc
{
  "title": "三打白骨精", "lang": "zh", "source": "三打白骨精-script.md",
  "scenes": [{
    "id": "1-2", "location": "白虎岭乱石坡", "time": "日", "intExt": "外",
    "characters": ["孙悟空", "唐僧", "猪八戒", "沙僧", "村姑"],
    "beats": [
      { "no": 1, "type": "action", "text": "雾散了一半，乱石坡下传来环佩声……", "closeup": false },
      { "no": 2, "type": "dialogue", "speaker": "猪八戒", "emotion": "眼睛发直", "line": "女菩萨，青罐里提的是什么？" }
    ]
  }]
}
```

- `beats[].no` 场內连号；动作与台词严格按原文顺序。
- 台词原文**逐字保留**（含标点），后续 `dialogue-coverage` 门靠它比对。
- 解析即消毒：`△` 符号只存在于原文，不进任何下游产物。

## 格式不对怎么办

- 报 `无法识别`：把该行改成上表五种行型之一；动作忘写 `△` 是最常见原因。
- 报 `场号重复` / `场头之前出现内容`：检查场号与 `人物：` 行位置。
- 用户只有小说/梗概没有分场剧本：先按本格式改写成剧本再进入管线——**不要绕过解析器**，下游所有门的可追溯性都建立在 scenes.json 上。
